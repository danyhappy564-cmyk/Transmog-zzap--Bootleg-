■ 이게 뭐예요

내 PMC/스캐브가 입은 장비의 "겉모습만" 다른 아이템 모습으로 바꿔 주는 모드입니다. (성능·방어력은 그대로예요. 롤플레이/코디용)
인벤토리에서 아이템 우클릭 → Transmog → "Set as PMC ○○" 고르면 끝.
숨기기(Hide)와 되돌리기(Reset)도 있습니다.
대상: 방탄복 / 조끼 / 가방 / 안경 / 얼굴 가리개 / 헬멧 / 헤드셋 / 완장

■ 이번에 한 것

- SPT 4.1에서 돌아가게 포팅했습니다. (원본은 4.0용)
- 원래는 Custom Interactions 모드를 따로 깔아야 했는데, 필요한 부분을 안에 합쳐서 이제 파일 하나(Transmog.dll)면 됩니다.
- 설정 파일과 모드 ID는 원본 그대로라서, 4.0 때 쓰던 설정이 그대로 이어집니다.
- 제 PC에서 동작하는 건 확인했습니다. 다만 스캐브 변환, 옷 가게 화면, 히드아웃 짐 같은 걸 하나하나 다 확인한 건 아니에요.

■ 설치

1. Transmog-1.3.1.1.zip 풀어서 SPT 폴더에 덮어쓰기 (BepInEx/plugins/Transmog/Transmog.dll)
2. 예전 4.0용 Transmog.dll 이 있으면 꼭 지우기 (같은 모드라 둘 다 있으면 안 됩니다)
3. Custom Interactions 는 안 깔아도 됩니다. (다른 모드 때문에 깔려 있어도 충돌 안 나게 만들었어요)

■ 설정 (F12 → Transmog)

- Show Scav in transmog menu : 스캐브용 메뉴도 보기 (기본 꺼짐)
- Show original equipment for Scav in the lobby : 진영 선택 화면에서 스캐브 원래 장비 보기
- Affect ingame player entity : 레이드 안 내 모델에도 적용 (바꾸면 다음 레이드부터)
